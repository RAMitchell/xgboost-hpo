# Expanded-space collection: 50 datasets × 40 configurations × one split

Authorized 2026-09-25; run in the background with **16 physical CPU cores maximum**. No cloud resources. This is a new collection, not a modification of old frozen studies.

## Admission and split

Candidate pool: the120one-per-family source representatives from dataset_breadth; all59evaluation families excluded. Prefer18binary,17multiclass,15regression datasets, admitted in deterministic metadata-only hash order within type. If a type exhausts admissible candidates, fill remaining slots from other source types in the saved deterministic order. Stop after50admitted source families. Record every exclusion; never replace a dataset because of objective performance. Candidate ordering, admission policy, hyperparameter samples and scripts frozen before production outcomes. Previous benchmark data were examined; this collection is not untouched confirmation.

Download public OpenML data by ID with provenance and cached metadata. Resource admission:100–500,000raw rows,1–5,000features,at most30millionraw feature cells. Multiclass maximum50classes; minimum10examples per class after row sampling. Single-target supervised data only. Metadata row/feature counts must be available; failures are recorded. Sparse frames unsupported for this tranche. Native categoricals, train-only category vocabulary; unseen validation categories become missing. No target encoding. Numerical infinities become missing and are counted. Drop missing targets.

Subsample deterministically to min(20,000rows,floor(4,000,000/n_features)) with stratification for classification. This is a resource-bounded tranche and is not a full-row benchmark. One60/20/20train/validation/test partition, grouping identical feature rows. Classification uses shuffled stratified group5folds: one testfold, onevalidationfold, remainingtrain. Regression uses grouped shuffle splits. Require allclassificationclasses ineachsplit, and positive regression variation. Save hashes/rowindices and disjoint-group checks. Test arrays written during preparation, never opened by collection or used for selection. Preserve classification/regression diversity and registry-defined family independence; the registry is not a proof of all possible aliases.
